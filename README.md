# Unequal_barriers_AMBIO_2026

This repository allows the replication of the results from the paper Neyret M., Lavorel S., Locatelli B., and Martin Lopez B. 2026. Unequal barriers to Nature's Contributions to People impact quality of life. AMBIO. https://doi.org/10.1007/s13280-026-02482-z

1. The file Barriers_data_prep.R is provided as an information on how raw data is pre-formatted for analysis. For data privacy reasons, only the pre-formatted data necessary to replicate the main results is provided.
2. Get the pre-formatted data from https://doi.org/10.57745/ENKAUD.
3. Rename the file config.R.template to config.R and fill in survey_data_path the path to the obtained data.
4. Results can be reproduced by running Barriers_data_analyses.R
